# 🛒 Zepto Inventory & Supply Chain Analytics

This project presents an end-to-end inventory and supply chain analytics solution built using Zepto's product inventory dataset. SQL Server was used for data cleaning and business analysis, while Power BI was used to build an interactive dashboard for visualizing key inventory and revenue metrics.

The objective is to transform raw inventory data into meaningful business insights that support inventory optimization, pricing analysis, and operational decision-making.

✔️ End-to-end SQL + Power BI analytics project

## 🎯 Project Objectives

The project focuses on solving practical inventory management problems by:

- Preparing and cleaning retail inventory data using SQL Server.
- Performing exploratory data analysis (EDA) on product inventory.
- Analyzing inventory value, revenue opportunity, discounts, and stock availability.
- Identifying high-value products and categories.
- Building an interactive Power BI dashboard for business stakeholders.
- Generating actionable insights to support inventory planning and decision-making.
---

# 📂 Dataset Overview

The dataset contains product-level inventory information collected from Zepto's online product catalog. Each record represents a unique product SKU along with pricing, inventory availability, discounts, and product category details.

### Dataset includes:

- SKU ID
- Product Name
- Category
- Maximum Retail Price (MRP)
- Discounted Selling Price
- Discount Percentage
- Available Quantity
- Product Weight
- Stock Status

# 🔄 Project Workflow

### 1️⃣ Database Setup
- Created the inventory database in SQL Server.
- Imported and validated the product dataset.

### 2️⃣ Data Cleaning
- Checked for missing and duplicate records.
- Standardized pricing and inventory fields.
- Validated discount calculations and data consistency.

### 3️⃣ Exploratory Data Analysis (EDA)
Performed SQL analysis to understand:
- Product distribution
- Category-wise inventory
- Pricing patterns
- Discount trends
- Stock availability

### 4️⃣ Business Analysis
Solved **23 business-focused SQL problems** covering:
- Inventory valuation
- Revenue opportunity
- Product and category performance
- Discount analysis
- Stock availability
- Pricing insights
- Time-to-stock-out simulation

### 5️⃣ Dashboard Development
Built an interactive Power BI dashboard featuring:
- Executive KPI cards
- Revenue opportunity analysis
- Inventory value analysis
- Category performance
- Stock status distribution
- Top revenue-generating products
- Average discount analysis

# 📈 Business Questions Addressed

The SQL analysis was performed to answer key business questions, including:

1. How many products are available in the inventory?
2. What is the total inventory value?
3. What is the estimated revenue opportunity?
4. Which product categories generate the highest revenue?
5. Which categories have the highest inventory value?
6. Which products are currently out of stock?
7. What is the average discount across product categories?
8. Which are the top revenue-generating products?
9. Which categories maintain the highest inventory levels?
10. Which products have the highest discount percentages?
11. Which products require immediate replenishment?
12. How is inventory distributed across categories?
13. Which categories contribute the most to overall business value?
14. How long will current inventory last based on stock levels?

> **A complete set of SQL queries is available in the `SQL Analysis.sql` file.**
