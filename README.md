# 🛒 Zepto Inventory & Supply Chain Analytics

This project presents an end-to-end inventory and supply chain analytics solution built using Zepto's product inventory dataset. SQL Server was used for data cleaning and business analysis, while Power BI was used to build an interactive dashboard for visualizing key inventory and revenue metrics.

The objective is to transform raw inventory data into meaningful business insights that support inventory optimization, pricing analysis, and operational decision-making.

---

## 📌 Project Highlights

✔️ End-to-end SQL + Power BI analytics project

✔️ Inventory and supply chain focused business case

✔️ 23 business-driven SQL analysis queries

✔️ Interactive executive dashboard with KPIs

✔️ Business recommendations based on data analysis

✔️ Designed for Business Analyst, Supply Chain Analyst, and Operations Analyst roles

---

## 🎯 Project Objectives

The project focuses on solving practical inventory management problems by:

- Preparing and cleaning retail inventory data using SQL Server.
- Performing exploratory data analysis (EDA) on product inventory.
- Analyzing inventory value, revenue opportunity, discounts, and stock availability.
- Identifying high-value products and categories.
- Building an interactive Power BI dashboard for business stakeholders.
- Generating actionable insights to support inventory planning and decision-making.
